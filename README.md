# EvoMatRSI

**Evidence-Grounded Recursive Self-Improvement for Materials Research Agents**

EvoMatRSI is a research direction for controlled Agent-level recursive self-improvement in materials science. The goal is to help research agents accumulate, validate, reuse, and roll back experience, skills, workflows, and decision policies across literature, databases, computational simulation, experiment planning, and automated laboratories.

The current design keeps the foundation model fixed and focuses on evidence-grounded improvement with explicit provenance, validation, promotion, regression checks, and rollback.

The initial validation path is VASP-first, with staged extensions to ASE, PyBaMM, materials databases, literature workflows, simulated laboratories, and controlled real-lab integrations.
